# --- The one that matters ---
# onnxruntime-qnn 2.x is a PLUGIN execution provider: it loads into stock
# onnxruntime (>= 1.24) rather than replacing it, and bundles the Hexagon
# backend (QnnHtp.dll, QNN SDK 2.50.40 as of 2.6.0).
#
# It is invisible until registered, and the classic
# providers=[("QNNExecutionProvider", ...)] argument silently yields a CPU-only
# session with it. All code here goes through scripts/qnn_ep.py, which
# registers the plugin, attaches it properly, and verifies it attached.
onnxruntime>=1.24.2
onnxruntime-qnn>=2.6.0
